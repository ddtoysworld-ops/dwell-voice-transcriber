# 华语 WhatsApp 语音识别修正（2026-10-26）

公开的 `v0.1.0` 在另一台使用华语界面的 WhatsApp Web 浏览器上没有显示转写按钮。插件已启用；Manifest V3 的 service worker 显示“Inactive”属于空闲状态，不能单凭它判断插件故障。检查源码后发现，旧版只识别英文语音标签；这属于代码层面的原因判断，未取得该浏览器的实际 DOM 快照。

`v0.1.1` 增加华语语音标签及消息内播放／进度控件的识别，同时排除视频消息。21 项单元测试、插件配置检查、Chrome 界面模拟测试，以及测试／验收／正式包检查均通过。用户已在原本受影响的浏览器上确认可使用，因此允许更新 GitHub。旧版 `v0.1.0` 保留作历史版本，不再推荐给客服安装。
